Installation Complete

Phoenix has been installed in your /Applications folder.

To launch Phoenix:
  1. Open Finder and click Applications in the sidebar.
  2. Double-click Resistine (the Phoenix app) to start it.

You can also open Spotlight (⌘ Space), type Phoenix, and press Return.

First launch

The first time you open Phoenix, macOS may ask you to:

  • Approve the bundled system extension for VPN networking.
  • Allow Full Disk Access for the antivirus on-access scanner.
  • Confirm notification permissions for security alerts.

Phoenix will guide you through each prompt. These approvals only need to happen once.

Need help?

Open the Help plugin inside Phoenix for setup walkthroughs, or visit phoenix.exposed for documentation and support.
