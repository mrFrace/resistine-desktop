Welcome to Phoenix AI EDR

Phoenix AI Endpoint Detection and Response (AI EDR) is a unified security desktop app for Windows, Mac, and Linux.

What this installer does

  • Installs the Phoenix app (Resistine.app) into your /Applications folder.
  • Registers the bundled Network Extension for VPN (WireGuard) support.
  • Sets up the on-access antivirus helper (ClamAV) and update service.
  • Registers the app with Launch Services so Spotlight and Finder can find it.

Included features

  • VPN (WireGuard) with system-level Network Extension
  • Antivirus on-access scanning (ClamAV)
  • SIEM endpoint agent (Wazuh) and endpoint management
  • AI assistant chat for security guidance

Requirements

  • macOS 13.0 (Ventura) or later
  • Apple Silicon (arm64) or Intel (x86_64)
  • Administrator privileges (required to install system components)
